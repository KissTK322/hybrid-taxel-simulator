# Hybrid Taxel Simulator

Interactive simulator of a hybrid piezoresistive + capacitive tactile taxel (single offline HTML page).
Open: https://kisstk322.github.io/hybrid-taxel-simulator/

Semi-analytical model for exploring trends, not a validated design tool. Values marked ⚠ in the page are guesses that still need measurement.
Uses three.js r160 (MIT License).
