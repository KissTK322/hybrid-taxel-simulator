สมมติฐานของ model (อ่านก่อนเชื่อตัวเลข)

  • ลำดับชั้นของ stack (ล่าง→บน): E1 → base PI → dielectric → E2 → cover PI · E1 อยู่ผิวล่างสุดจึงแตะชั้น CNT ของ dome ได้โดยตรง ตรงกับที่ model ช่อง A คิด · ⚠ base PI อยู่ระหว่าง E1 กับ E2 ด้วย แต่ C_B ของ model คิดเฉพาะ dielectric (ไม่รวม PI ที่ต่ออนุกรม) ค่า C_B จริงจึงต่ำกว่า model เล็กน้อย — ตั้ง "PI ที่รองรับ E1" = 0 ถ้า E1 พิมพ์ลงบน dielectric โดยตรง
  • Large deflection: เมื่อแผ่นบนยุบมากเทียบกับความหนา แผ่นจะยืดและแข็งขึ้น ใช้รูป w_linear = w(1 + β(w/tₑ)²) กับค่าเฉลี่ยของการยุบ โดย tₑ = √(12D/A) (A = ความแข็งแบบยืดรวมของทุกชั้น) · β เป็นค่าของแผ่นขอบยึดแน่นไม่เลื่อน ซึ่งเป็นขอบบนของความแข็ง (border ยางจริงยอมให้ขอบขยับได้บ้าง) · ปิดได้ในหมวด “การคำนวณ”
  • border ยุบตัว: border เป็นแถบยาง TPU ที่ยึดสองหน้า รับแรงส่วนที่ dome ไม่ได้รับ ยุบ = (p·a² − ΣF_dome)/k_b โดย k_b = E(1+2S²)A_b/H₀ (Gent–Lindley) ทั้ง stack จึงเลื่อนลงและ dome ที่เตี้ยกว่าแตะตามได้ที่แรงสูง · ปิดได้ในหมวด “การคำนวณ”
  • ความต้านทานช่อง A (สมการใหม่): ต่อ dome = ผิวสัมผัส ρₜ/A_r + กระจายจากวงสัมผัส R_s/8π + ทางเดินบนฟิล์มตามผิว dome · ถ้า E1 เป็น resin-CNT คิดเป็นแผ่นต้านทานและแก้เป็นโครงข่ายด้วย superposition · ρₜ และ film □ fit กับกระแสของ MEMS 2026
  • วัสดุ piezo เป็น dielectric (แบบที่ยืนยันแล้ว): เลือกวัสดุ piezo จาก Table 1 ที่ช่อง “วัสดุ dielectric” สัญญาณ piezo อ่านระหว่าง E1 กับ E2 ไม่มี E3 · C ของคู่เดียวกันคำนวณด้วย model dielectric เดิม ซึ่งให้ ΔC ≈ 0 สำหรับวัสดุเนื้อตัน (แข็งระดับ GPa) · รูปแบบพรุนใช้ d33 ของเนื้อตันและความแข็ง Gibson–Ashby ⚠ ไม่มีค่าที่วัดจริง · ทางเลือกเดิม (piezo เป็นชั้นที่สามบน E2 พร้อม E3) ยังเลือกได้ที่ช่อง “ชั้นบนสุด”
  • สัญญาณ piezo: โหมด d33 อย่างเดียว Q = d33·p·A บนพื้นที่ electrode, ไม่รวม d31 จากการดัด · ฟิล์มเป็นแหล่งประจุขนานกับ C ของฟิล์ม + สาย และรั่วผ่าน R ขาเข้า · pyroelectric: Q = p_pyro·A·ΔT · E3 เป็นโลหะบาง
  • อุณหภูมิ: ปรับ modulus ของ TPU และ dielectric, εr (TCC) และ R ของ CNT (TCR) แบบเส้นตรงตาม ΔT · calibration อยู่ที่ ΔT = 0 · ไม่รวมการขยายตัวตามความร้อน (gap 30 µm เปลี่ยนน้อยกว่า 0.1 µm ต่อ 10 K เพราะ border กับ dome เป็น TPU เดียวกัน)
  • noise: noise ของชิปอ่าน C รวมกับ noise ของระบบจริง (ค่าเริ่มต้น 1 fF ⚠) แบบ root-sum-square
  • แผ่นบน (stack capacitive) เป็นแผ่นสี่เหลี่ยมยึดแน่นที่ border รับแรงกดสม่ำเสมอ แก้ด้วย finite difference (biharmonic, 13-point) · ตรวจแล้วได้ w = 0.00128 qL⁴/D (ทฤษฎี 0.00126) · ไม่รวม large-deflection / membrane stretching
  • dome เป็น paraboloid สัมผัสแบบ Hertz (รัศมีปลาย R = r²/2h) · ใช้ได้ดีเมื่อ dome ยุบไม่เกิน ~30% ของความสูง · แผ่นบนแข็งกว่า TPU มาก
  • ความต้านทานช่อง A = constriction (Holm, ρ/4a) + film/tunneling (ρₜ/A_real) + ทางเดินบน film ของ dome + film ถึง pad · พื้นที่สัมผัสจริง A_real = F/H (asperity) ไม่เกินพื้นที่ Hertz
  • CNT: percolation σ = σ₀(φ − φc)^t · fit ให้ 5 wt% ≈ 4×10⁻³ S/cm ตามกราฟ Zaki AFM 2025 Fig. 2I · wt% อื่นเป็นการ extrapolate
  • การพิมพ์: Jacobs working curve Cd = Dp·ln(t/tc) · fit ให้ 5 wt% ได้ 20 µm ที่ 350 s (AFM 2025 p.6) · จุดที่สอง (50 µm ที่ 1000 s) ไม่พบใน paper — ต้องยืนยัน · Grayscale ใช้สูตร z = Dp·ln(tG/(T₀·255)) ของ Zaki
  • C_A (E1 กับชั้น CNT ก่อนแตะ) = ∫ε₀/gap dA แบบ parallel-plate ไม่รวม fringing
  • C_B (E1–E2): dielectric ตันใช้ shape factor (ยางตันโป่งข้าง ยุบยาก) · dielectric พรุนใช้ Gibson–Ashby E(1−φ)² ที่รูพรุนค่อย ๆ ยุบ · εr ผสมแบบ Lichtenecker
  • Creep = standard linear solid (ลด modulus ตามเวลา) ใช้กับ TPU และ dielectric · drift ของ R ตาม log ของเวลา · ไม่ได้จำลอง hysteresis ของ loop ขึ้น-ลง
  • ค่าที่มี ⚠ (modulus ของ TPU, TCR, creep) เป็นค่าเดา ต้องวัดจริงก่อนใช้ตัวเลขในงานวิจัย · ใช้แท็บ "ข้อมูลจริง" fit ค่าเหล่านี้
  • model นี้ใช้เพื่อดูแนวโน้มและ trade-off ไม่ใช่ FEM · ถ้าจะออกแบบจริงควรยืนยันด้วย COMSOL/Abaqus และการวัด
